## 작업 순서와 폴더

2026년 11월 23일부터 이 편을 다섯 단계로 만듭니다. 단계마다 결과를 확인받고 다음 단계로 넘어갑니다. 뒤 단계에서 앞 단계를 고치면 바뀐 부분만 다시 만듭니다.

| 단계 | 하는 일 | 폴더 | 확인하는 곳 |
|---|---|---|---|
| 1. 대본 분석 | 구간 요점·시간, 시청자 질문과 감정 흐름, 화면 대응표, 사람과 주홍을 쓰는 법, 연구 장면 원칙, 콘티에서 바꿀 것 | `storyboard/대본분석.md` | 문서 |
| 2. 스토리보드 | 콘티 75장면을 4초에 1컷 샷 리스트로 나눔(약 111샷, S001부터, 장면 번호 함께) | `storyboard/`, `shotlist/` | 콘티 검토 페이지 |
| 3. 이미지 제작 | 샷마다 다른 그림(이미 그린 19장은 한 번씩, 새로 약 92장). 그리기 전에 샷 수와 시간을 먼저 확인 | `shotlist/` | 비교 화면, 검토 페이지 |
| 4. 음성·음악 | 내레이션과 소리 | `recording/` | 목소리·소리 고르기 페이지 |
| 5. 조립·렌더 | HyperFrames 조립, 업로드 파일 | `export/` | 렌더 영상 |

- 단계마다 브랜치와 PR을 따로 둡니다(`soup-1-analysis` … `soup-5-assembly`).
- 그림·음성·음원·렌더는 저장소에 올리지 않습니다(`.gitignore`). 편이 끝나면(영상·썸네일·설명 업로드 뒤) [`tools/archive_task.py`](../../tools/archive_task.py)로 구글 드라이브에 옮기고 로컬에서 지웁니다.
- 1분 시험 영상은 [`export/test_1min/`](export/test_1min/REVIEW.md)에 있습니다.

## 11월 23일 오프닝 수정

“마지막 과자를 먹을 때는…”으로 바로 시작하는 첫머리가 생뚱맞아서, 사용자가 쓴 수정안으로 [생활 속 모순]과 [예상해 보기]의 질문 부분을 바꿨습니다. 맞춤법·띄어쓰기만 고치고, 두 컷에 걸치는 “남아 있었다면” 뒤에 쉼표 하나를 더했습니다(그 쉼에서 컷을 나눔). 결말의 되풀이 문장도 새 첫머리에 맞췄습니다.

| 고친 곳 | 전 | 후 |
|---|---|---|
| 첫 장면 | 마지막 과자를 먹을 때는, 그게 마지막인지 몰랐습니다. / 한 번 더 손을 넣었는데, 손끝에 봉지 바닥이 닿습니다. / 그제야 생각하죠. 아, 다 먹었네. | 봉지의 마지막 남은 과자를 집었을 때, 깜짝 놀랐습니다. / 혹시나 하고 한 번 더 손을 넣어보지만, 역시나 다 먹었습니다. |
| 맛과 손 | 첫 입은 조금 눅눅했습니다. … 손은 몇 번이고 같은 자리로 갔죠. 언제 그만 먹겠다고 생각했는지도 잘 모르겠습니다. | 별로 좋아하지 않는 과자인 데다, 누군가 먹다 놔둔 과자라서 첫 입은 조금 눅눅한 맛이었던 것 같습니다. 솔직히 그다음부터는 무슨 맛인지 잘 기억이 나지 않습니다. / 그렇게 맛있지도 않았는데, 그만 먹겠다는 생각 자체가 나지 않았습니다. 기계적으로 과자를 집어 먹었던 것 같습니다. |
| 예상 질문 | 그 봉지에 과자가 조금 더 남아 있었다면, 같은 순간에 손을 멈췄을까요? [한 박자 쉼.] 아니면 한 번 더 집었을까요? | 봉지에 과자가 조금 더 남아 있었다면, 같은 순간에 손을 멈췄을까요? 아니면 계속 집어먹었을까요? / 그렇게 맛있지도 않았는데 말이죠… |
| 결말 되풀이 | 한 번 더 손을 넣었는데, 손끝에 봉지 바닥이 닿습니다. / 아, 다 먹었네. | 혹시나 하고 한 번 더 손을 넣어보지만, 역시나 다 먹었습니다. |

“그렇게 맛있지도 않았는데”는 셋째 문단 첫머리와 예상 질문 끝에 두 번 나옵니다. 앞 문장을 되받는 반복이라 그대로 둡니다. 화면은 새 그림 없이 C01~C09를 다시 나눴고, C04는 읽지 않는 정적 2초 컷이 됐습니다([화면 콘티](storyboard/콘티.md)).

## 연구 근거

- **수프 원연구, 2005년.** 54명이 토마토 수프를 먹었습니다. 두 그릇은 같은 크기와 외형이었습니다. 일반 그릇도 약 4분의 1이 남으면 직원이 보충했습니다. 자동 보충 쪽의 수프 섭취량이 평균 73% 많았다는 당시 보고와 두 조건의 배부름 설문에서 유의한 차이가 없었다는 결과를 구분해 전달합니다. 20분은 실험 시간입니다. [Wansink·Painter·North 원논문](https://www.appstate.edu/~steelekm/classes/psy5150/Documents/Bottomless_Soup-OR_2005.pdf)
- **코넬대 조사, 2018년.** 코넬대 조사위원회는 데이터 오보고, 부적절한 통계 기법 등 완싱크의 연구 부정을 확인했습니다. 11월 9일 결정대로 영상에서는 읽지 않고, 재현 연구를 살펴본 배경으로 기록만 남깁니다. [코넬대 공식 발표](https://news.cornell.edu/stories/2018/09/provost-issues-statement-wansink-academic-misconduct-investigation)
- **수프 독립 재현, 2024년 정식 출판.** 사전등록 연구의 주 분석은 464명으로, 자동 보충 쪽에서 평균 약 32% 더 먹었습니다. 일부 결과는 원연구와 달랐습니다. 두 수치는 각각 해당 연구의 일반 그릇 조건과 비교한 평균 섭취량 증가율입니다. 화면에는 `2005 원연구 보고 · +73%`와 `2024 독립 재현 · 약 +32%`를 연구명과 함께 차례로 표시합니다. [Lopez 외 논문 서지·초록](https://pubmed.ncbi.nlm.nih.gov/37917442/) · [저자 공개 본문과 표 1](https://www.researchgate.net/publication/375318545_Visual_Cues_and_Food_Intake_A_Preregistered_Replication_of) · [연구 사전등록](https://osf.io/ux42g/)
- **영화관 팝콘, 2005년.** 원논문은 14일 된 팝콘을 받은 관객 중 큰 통 조건에서 더 먹었다고 보고했습니다. 중형과 대형 조건은 통과 처음 담긴 팝콘의 양이 함께 달랐습니다. 2017년 정정 기록을 확인했으며 정정 전문은 확인하지 못했습니다. 대본은 당시 보고의 방향만 소개하고 상세 수치와 정정 사실은 읽지 않습니다. [Wansink·Kim 원논문 초록](https://pubmed.ncbi.nlm.nih.gov/16053812/) · [팝콘 논문 정정 기록](https://pubmed.ncbi.nlm.nih.gov/28889859/)
- **몸의 감각.** 위가 늘어나면서 전해지는 신호는 배부름에 관여합니다. 수프 연구에서 배부름은 참가자의 설문 응답으로 측정했습니다. 실제 먹은 양과 주관적으로 느낀 배부름은 별개의 측정치입니다. [위 팽창과 뇌 반응을 살핀 인체 연구](https://pubmed.ncbi.nlm.nih.gov/18155924/) · [수프 원논문 측정 방법](https://www.appstate.edu/~steelekm/classes/psy5150/Documents/Bottomless_Soup-OR_2005.pdf)
