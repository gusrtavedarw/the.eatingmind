# 먹는마음 · 수프·팝콘 편 대본 분석

작업 1단계 문서입니다(2026-11-23). [녹음 대본](../내레이션_녹음용.txt), [제작 메모](../제작메모.md), [화면 콘티 v1](콘티.md), [1분 시험 영상](../export/test_1min/REVIEW.md)의 실제 내레이션 길이를 바탕으로 썼습니다. 다음 단계(스토리보드·샷 리스트)는 이 문서를 기준으로 콘티를 고치고 4초에 1컷으로 나눕니다.

## 한눈에

- **중심 질문:** 먹기를 끝내는 순간은 무엇이 정할까? (제목안: 마지막 한 입은 누가 정했을까?)
- **답의 방향:** 몸의 느낌과 눈앞에서 줄어드는 음식의 모습이 함께 영향을 준다. 둘 중 하나로 단정하지 않는다.
- **첫 장면과 회수:** 빈 봉지에 다시 손을 넣는 장면. 마지막에 같은 장면을 넓혀 보면, 봉지 안이 보이지 않았고 시선은 화면에 있었다.
- **남기는 것:** 정답 대신 질문 하나. "오늘 내가 먹기를 끝낸 순간에는 어떤 이유가 있었을까?"

## 2. 시청자의 질문과 감정 흐름

감정은 **머쓱함 → 궁금함 → 놀람 → 의심 → 믿음 → 납득 → 익숙함 → 너그러움 → 평온** 순서로 흐릅니다. 자책이나 경고로 흐르지 않게, 화면은 먹는 사람과 음식을 탓하는 모습으로 그리지 않습니다.

| 구간 | 시청자 머릿속 질문 | 감정 | 화면이 할 일 |
|---|---|---|---|
| 생활 속 모순 | "어, 벌써 다 먹었네?" → "맛도 없었는데 왜 계속 먹었지?" | 머쓱함, 자기 경험이 겹침 | 손과 봉지만 가깝게. 바스락 뒤 정적으로 그 순간을 붙잡는다. |
| 예상해 보기 | "더 남아 있었으면… 아마 더 먹었겠지." | 살짝 찔림, 궁금함 | 남은 봉지와 멈춘 손. 접시 세 개로 "줄어드는 모습"이라는 말을 그림으로 처음 보여 준다. |
| 수프 | "바닥에서 채워지는 그릇이라고?" → "73%나?" → "배부름은 비슷했다고?" | 신기함, 놀람, 의아함 | 장치의 비밀(관)을 단면으로 드러내고, 먹은 양과 배부름을 서로 다른 그림으로 나눈다. |
| 독립 재현 | "그 숫자 믿어도 돼?" | 의심 → 안도 | 같은 장치를 다른 손들이 다시 차리는 모습. 막대가 줄었지만 같은 쪽으로 기운다. |
| 팝콘 | "맛없으면 덜 먹겠지?" | 예상이 빗나가는 작은 반전 | 영화관의 어둠과 눅눅한 팝콘. 단면도로 처음 담긴 양이 달랐음을 정직하게 보여 준다. |
| 작동 원리 | "그래서 왜 그런데?" | 납득, 정리되는 느낌 | 그릇 벽의 자국(눈의 어림)과 위 해부도(몸의 신호)가 한 마침표로 모인다. |
| 내 경험에 적용 | "우리 집 과자 봉지도 그렇네." | 익숙함, 작은 깨달음 | 낮의 거실과 식탁. 봉지 속은 안 보이고 접시는 셀 수 있다. |
| 처음 장면 | "그날 나는 뭘 보고 있었지?" | 너그러움, 차분한 궁금함 | 같은 구도를 새로 그리고, 처음으로 몸(뒷모습)과 TV가 화면에 들어온다. |
| 작은 관찰 | "다음 끼니 끝에 한번 떠올려 볼까." | 평온, 가벼움 | 밤에서 아침으로. 마침표 점 세 개로 여러 이유가 가능함을 보여 준다. |

## 4. 사람과 주홍

### 사람

- C62까지는 **손만** 보입니다. 오프닝의 주인공, 실험 참가자, 직원, 영화관 관객, 여럿이 먹는 식탁 모두 손과 소매까지만 그립니다. 시청자가 화면 속 손을 자기 손으로 보게 하려는 것입니다.
- 오프닝·적용·결말의 주인공은 한 사람입니다. 기준 그림 `style_scene.png`처럼 **맨팔의 오른손**으로 맞추고, 몸이 드러날 때도 반소매 차림으로 잇습니다.
- 몸은 결말 **C63**에서 처음, 소파에 앉은 뒷모습 실루엣으로 드러납니다. 얼굴은 끝까지 그늘에 둡니다. C64(고개 숙임), C72(식탁 의자 옆모습)도 같습니다.
- 4초에 1컷으로 나누면 손이 나오는 샷이 늘어납니다. 손·팔이 나오는 그림은 모두 `tools/check-img.sh`로 검수하고, 팔 부분은 확대해 직접 봅니다.

### 주홍

주홍은 장면이 끌어당기는 **한 가지**에만 칠합니다. 구간마다 주홍이 옮겨 가는 길이 이야기의 흐름과 같습니다.

| 구간 | 주홍을 칠하는 것 |
|---|---|
| 생활 속 모순 · 예상해 보기 | 과자(봉지 안 마지막 한 조각, 손끝의 부스러기, 접시 위 과자) |
| 수프 · 독립 재현 | 수프. 숫자 카드에서는 자동 그릇 막대 |
| 팝콘 | 팝콘 |
| 작동 원리 | 수프 → 위 속 음식 → 신경을 따라 올라가는 점 → 가운데 마침표 → 겹친 부분 |
| 내 경험에 적용 | 과자, 가운데 접시의 음식 |
| 처음 장면 다시 보기 | 과자와 부스러기. **TV 빛에는 칠하지 않는다**(흰 종이와 해칭만). 화면이 원인이라고 정하지 않기 위해서다. |
| 작은 관찰 · 마지막 화면 | 남은 반찬 한 점, 마침표 점 세 개, 그릇 바닥 수프 한 줄기 |

## 5. 연구 장면 원칙

- **실제 인물·기관은 그리지 않습니다.** 연구자 얼굴·초상, 대학 건물·로고, 논문 표지는 넣지 않습니다. 연구 부정 조사(2018년)는 대본에서 읽지 않으므로 화면에도 넣지 않습니다.
- **장치는 원논문 설명 안에서만 그립니다.** 식탁 아래 통에서 관이 그릇 바닥으로 올라가는 구조, 같은 모양의 두 그릇, 일반 그릇을 국자로 채우는 직원의 손까지입니다. 확인하지 않은 세부(통의 크기, 펌프 등)는 만들지 않습니다.
- **먹은 양과 배부름은 다른 그림으로 보여 줍니다.** 먹은 양은 막대, 배부름은 설문지입니다. "배부름에 차이가 없었다"를 "똑같이 배불렀다"처럼 보이게 그리지 않고, 두 장의 표시가 비슷한 자리에 있는 정도로만 그립니다.
- **원연구와 재현은 구분해 보여 줍니다.** 숫자는 숫자 비교 카드(C19 → C25) 한 곳에만 나오며, 막대 길이는 실제 비율(1.73배, 1.32배)로 맞춥니다. 카드 글자는 자막 자리와 겹치지 않는 막대 위에 두고, 그 순간 자막의 핵심어만 줄여 적습니다(`2005 원연구 보고 · +73%`, `2024 독립 재현 · 약 +32%`). 자막과 자리가 겹치지 않고 핵심어만 줄인 카드라 그대로 둡니다.
- **팝콘의 한계는 그림으로 정직하게 보여 줍니다.** 중간 통과 큰 통의 단면에 처음 담긴 높이 선을 그려, 통 크기와 양이 함께 달랐음을 보이게 합니다.
- **몸의 신호는 옛 의학 판화식 도판으로 그립니다.** 사람 몸의 윤곽 없이 기관만 종이 위에 놓습니다. 재지 않은 것은 바늘이 멈춘 계기로 표시하고, 도파민·뇌 회로 같은 그림은 덧붙이지 않습니다.
- **창작 장면과 연구 장면을 구분합니다.** 봉지·거실 장면은 창작(제작 메모에 밝힘)이고 밤의 빛입니다. 연구 장면은 실험실 식탁이나 종이 위 도판이고 낮의 빛입니다.

## 6. 콘티에서 바꿀 것

2단계(스토리보드·샷 리스트)에서 반영합니다. 각 항목은 그 단계를 시작할 때 다시 확인받습니다.

1. **샷 수의 기준 속도.** 실측 속도(분당 약 363음절, C01~C11 기준)로 나누면 약 93~95샷, 콘티 예상 속도(분당 265음절)로 나누면 약 111샷입니다. 실측 속도를 기준으로 하면 그릴 그림이 약 16장 줄고, 녹음 뒤 샷이 남는 일도 줄어듭니다.
2. **길어서 나눌 장면.** 실측 속도로 6초가 넘는 18장면은 2~3샷으로 나누고, 샷마다 다른 그림을 씁니다. 같은 장면의 상태 변화(예: 접시가 줄어듦, 선이 모임)는 앞 그림을 참고해 새로 그립니다.

   | 장면 | 실측 길이 | 샷 | 나누는 자리 | 그림 방향 |
   |---|---|---|---|---|
   | C05 | 12.1초 | 3 | "…과자인 데다," / "누군가 먹다 놔둔…" / "솔직히…" | 별로 좋아하지 않는 과자 봉지 → 남이 먹다 둔 봉지 입구와 눅눅한 한 조각 → 위에서 본 탁자(이미 그림). 1분 시험에서 가장 약했던 장면이 풀림 |
   | C06 | 8.7초 | 2 | "…나지 않았습니다." / "기계적으로…" | 손의 잔상(이미 그림) → 같은 동작을 다른 각도에서 |
   | C10 | 6.2초 | 2 | "…돌보는 지식." / "안녕하세요…" | 빈 봉지 정물(이미 그림) → 부스러기 가까이 |
   | C11 | 9.7초 | 2 | "…살펴보겠습니다." / "먹은 만큼…" | 질문을 여는 그림 → 접시 셋(이미 그림) |
   | C20 | 9.5초 | 2 | "…물었습니다." / "그 응답에서는…" | 빈 그릇 앞 설문지 한 장 → 두 장의 표시 |
   | C21 | 7.6초 | 2 | "…믿을 수 있을까요?" / "다른 팀이…" | 홀로 놓인 자동 그릇 → 같은 장치 도면이 다른 탁자로 |
   | C27 | 6.7초 | 2 | "…달라지자" / "먹는 양도…" | 위에서 본 두 그릇 → 두 연구의 식탁이 나란히 |
   | C34 | 6.7초 | 2 | "…양에 따라" / "먹는 양이…" | 큰 통으로 들어가는 손 → 상영이 끝난 좌석의 통 |
   | C35 | 6.9초 | 2 | "…돌아가 볼까요?" / "봉지에…" | 수프에서 봉지로 넘어가는 그림 → 두 봉지 |
   | C36 | 6.5초 | 2 | "…모습을 보고" / "얼마나…" | 자국 나이테 → 한 숟가락 뒤 한 칸 내려간 단면 |
   | C37 | 7.2초 | 2 | "…움직여도" / "그만큼…" | 가득한 자동 그릇과 숟가락들 → 그릇 바닥 구멍 가까이 |
   | C45 | 6.3초 | 2 | "…판단에는," / "몸의 느낌과…" | 위와 그릇 두 출발점 → 선이 마침표로 모임(상태 변화). 핵심 그림이라 1샷으로 둘 수도 있음 |
   | C46 | 6.5초 | 2 | "…느낄 때," / "어떤 날은 빈 접시를…" | 수프가 조금 남은 그릇과 숟가락 → 빈 접시 |
   | C50 | 7.6초 | 2 | "…보이지 않으면" / "처음에…" | 불룩한 봉지 겉모습 → 단면 |
   | C58 | 9.7초 | 2 | "…달라집니다." / "수프 그릇에서…" | 가운데 접시 단면 → 수프 그릇과 접시가 나란히 |
   | C66 | 7.2초 | 2 | "…있었을까요?" / "우리는…" | TV 빛 아래 봉지 → 어두운 소파의 빈자리 |
   | C67 | 9.5초 | 2 | "…지나갈 때보다," / "그 사이에…" | 구겨 쥔 빈 봉지(지나침) → 펼친 봉지(들여다봄) |
   | C70 | 10.0초 | 3 | "…찼을 수도," / "…않았을 수도 있습니다." / "접시에…" | 작은 위 → 반찬 한 점 남은 접시 → 빈 접시. 한 줄 도판을 세 장으로 |

3. **종이 위 도판이 길게 이어지는 곳.** 작동 원리(C35–C47)는 13장면 중 11장면이, 수프·재현(C17–C23)은 7장면 중 6장면이 종이 위 오브제입니다. 나눌 때 새 샷 일부를 화면 가득 장면(손, 식탁, 수프 표면)으로 넣어 단조롭지 않게 합니다.
4. **이미 그린 19장.** C05·C06·C10·C11은 나뉘어 각각 한 샷에만 쓰고, 나머지 샷은 새로 그립니다. 1분 시험 영상은 5단계 조립 때 새 샷 리스트로 다시 만듭니다.
5. **번호.** 콘티의 C01~C75는 장면 번호로 그대로 두고, 샷은 S001부터 번호를 붙여 장면 번호를 함께 적습니다.

## 7. 윤문 적용 내역 (2026-11-24)

[im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 humanize-korean v2.4.8로 읽는 문장만 윤문했습니다. 제목·화자 줄, 구간 이름, 대괄호 지시, 채널 인사는 넣지 않았습니다.

- **1차, 윤문 스킬:** 가벼움 경로, 변경률 0%. 스킬이 AI 티로 잡은 것은 연결어미 뒤 쉼표 4곳(넣어보지만, ×2 · 어둡고, · 있었고,)뿐이었습니다. 쉼표는 내레이션의 숨 쉬는 자리라 지우지 않고 기록만 남깁니다.
- **2차, 용어·흐름 점검:** 18곳을 반영했습니다.
  - 흐름 3곳: 팝콘 연구팀을 "수프 실험을 했던 연구팀"으로 밝힘, "팝콘을 담은 통도 중간 통과 큰 통, 두 가지였습니다." 추가, 작동 원리 첫머리에 "먼저 수프 그릇을 다시 보죠." 추가.
  - 용어 15곳: 응답·집단 → 대답·쪽, 미리 등록 → 미리 정해 공개, 증가 폭 → 더 먹은 양, 열나흘 → 이 주, 연구진 → 연구팀, 평범한 그릇·아래에서 조금씩 채워지는 그릇 → 일반 그릇·자동으로 채워지는 그릇, 어림·가늠 → 짐작·알기, 시선 → 눈 등.
- 콘티와 샷 리스트 문장도 같이 고쳤습니다. 추가 문장 때문에 전체가 약 4초 늘었습니다(샷 리스트 6:17 → 6:21).
- 2026-11-25 사용자 수정안으로 대본을 다시 썼습니다. 수프·재현·팝콘 문단은 초안 문장을 따라 위 윤문 가운데 8곳 정도가 그 전 표현으로 돌아갔습니다. 바뀐 내용은 [제작메모](../제작메모.md)의 11월 25일 항목에 있습니다.
