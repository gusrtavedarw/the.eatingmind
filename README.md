# 먹는마음

먹는 마음을 이해하고, 나를 돌보는 지식.

먹는 행동의 심리와 뇌과학을 다루는 교양 채널의 기획 자료, 대본 구조와 리서치 기록입니다. 최신 기획 반영: **2026-11-09**.

## 현재 작업

첫 영상 **수프·팝콘 편**의 녹음용 대본(v2)을 완성했습니다. 다음 작업은 낭독으로 실제 길이를 확인하고, 제목·썸네일을 확정하고, 화면 콘티를 만드는 일입니다. 디저트 배 편은 추후 제작으로 보류했습니다.

> 먹기를 끝내는 판단에는, 몸의 느낌과 눈앞에 보이는 음식의 양이 함께 영향을 준다.

- [녹음용 대본](production/visual-cues/v3/내레이션_녹음용.txt): 가족이 먹다 남긴 과자 봉지에서 시작하는 7단계 원고. 쉼 포함 약 7~8분 예상
- [제작 메모](production/visual-cues/v3/제작메모.md): 구간별 분량, 수정 내역, 근거표, 연출·낭독 메모
- [전체 정리](production/먹는마음_전체정리_2026-11-06.md): 채널 정체성, 확정 사항, 보류 사항과 다음 작업(11월 6일 기준)
- [확정 브리프](production/visual-cues/episode_brief.md): 현재 편의 시청자·메시지·감정 흐름·연구 검증 비중
- [구간별 기획안](production/visual-cues/v2/기획안.md): 생활 장면 오프닝과 7단계 전개
- [연구 메모 및 이전 기획](production/visual-cues/v1/기획안.md): 출처와 확인 한계 보존. 오프닝은 v2가 현재안
- [통합 페이지](index.html): 최신 기획, 대본 구조, 국내외 채널·도서·시즌 편성
- [첫 시즌 편성과 새 주제](notes/season-order-and-new-topics.md): 유튜브 추천 기준으로 정한 편성 순서, 새 주제와 근거

제목 **‘마지막 한 입은 누가 정했을까?’**, 썸네일 **‘언제 다 먹었지?’**는 미확정 제안입니다. 약 7~8분 분량은 낭독 전 추정입니다.

## 기본 대본 구조

**생활 속 모순 → 예상해 보기 → 실험과 발견 → 작동 원리 → 내 경험에 적용 → 처음 장면을 다시 보기 → 작은 관찰**

시청자가 질문을 갖게 되는 생활 장면에서 시작합니다. 연구자의 이름이나 실험 장치는 그 뒤에 등장합니다. 도입의 장면을 마지막에 다시 보며, 다음 식사에서 스스로 관찰할 질문을 남깁니다.

## 대본 스킬

[eating-mind-script](skills/eating-mind-script/SKILL.md)는 채널의 어조, 서사 구조, 연구 검증과 산출물 기준을 담은 재사용 가능한 Codex 스킬입니다. [세부 작성 가이드](skills/eating-mind-script/references/writing-guide.md)를 함께 제공합니다.

스킬을 설치한 환경에서의 사용 예:

```text
$eating-mind-script로 확정 브리프를 바탕으로 전체 녹음 대본을 써줘.
```

## 페이지와 참고 자료

`index.html`은 빌드 없이 여는 정적 페이지입니다. `assets/`, `notes/`, `channels.json`, `watchlist.csv`를 함께 유지해야 이미지·폰트·다운로드 링크가 작동합니다.
