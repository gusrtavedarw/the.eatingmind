# 먹는마음 콘텐츠 대본

먹는 행동에서 생긴 질문을 지식으로 살펴보고, 처음의 경험을 조금 더 구체적으로 이해하게 하는 교양 콘텐츠를 만든다. 최신 사용자 요청이 이 스킬의 기본값보다 우선한다.

## 채널의 기준

- 채널명은 **먹는마음**, 화자는 **구스타브**. 대화에 근거 없이 실명·소속·전문 자격·임상 경험을 부여하지 않는다.
- 주제는 먹는 행동의 심리, 뇌과학, 감정, 몸과 음식의 관계다. 지식 탐구와 치유·회복의 느낌을 함께 담는다. 치료 효과를 약속하거나 감량 요령으로 모든 주제를 마무리하지 않는다.
- 회복의 느낌은 첫 장면을 이해하는 방식이 달라지는 데서 만든다. 자기비난을 관찰로 바꾸되, 매번 ‘의지 문제가 아니다’라는 같은 결론을 붙이지 않는다.
- 말투는 차분한 성인 설명자의 자연스러운 합니다체. ‘합니다·죠·볼까요’를 문맥에 맞게 섞고, 시청자를 심문하거나 훈계하지 않는다.
- 마무리에 맞으면 **“먹는 마음을 이해하고, 나를 돌보는 지식. 먹는마음, 구스타브였습니다.”**를 사용한다. 짧은 부분 수정에 인사·슬로건을 억지로 넣지 않는다.

## 요청 범위부터 맞추기

사용자의 주제, 제공 자료, 기존 원고, 최신 피드백을 먼저 확인한다. 이미 합의한 내용을 다시 질문하지 않는다. 길이 지정이 없으면 본편은 약 7~8분을 작업 가안으로 삼되, 실제 낭독 전에는 예상 분량이라고 표시한다.

| 요청 | 완성할 결과 |
|---|---|
| 기획·구조 제안 | 중심 질문과 메시지, 7단계 구성, 실제 오프닝 대사, 중요한 전환과 결말 방향 |
| 대본 작성 | 구스타브가 읽을 수 있는 완결된 원고. 개요만 주고 멈추지 않는다. 근거 메모는 낭독 본문과 분리한다. |
| 오프닝 수정 | 대체 오프닝과 다음 구간 연결. 기존 결말이 옛 오프닝을 회수한다면 그 부분도 수정하거나 구체적 대체안을 준다. |
| 기존 원고 수정·검토 | 요청한 범위에 집중해 고친 원고를 준다. 핵심 변경 이유와 남은 사실 확인 사항만 간결하게 설명한다. |

작성 요청을 영상 제작·게시·음성 생성으로 확대하지 않는다. 파일을 저장할 때는 기존 프로젝트의 편별 구조를 따르고 사용자 원고를 보존한다. 파일이 필요하지 않은 간단한 제안은 대화 안에서 완성해도 된다.

## 기본 서사: 7단계

**생활 속 모순 → 예상해 보기 → 실험과 발견 → 작동 원리 → 내 경험에 적용 → 처음 장면을 다시 보기 → 작은 관찰**

아래는 이야기의 기능이다. 모든 편에 같은 장면·문장·분량을 강제하거나 일곱 개의 화면 제목을 붙이지 않는다. 짧은 형식에서는 인접 단계를 합칠 수 있다.

| 단계 | 해야 할 일 | 연결 기준 |
|---|---|---|
| 1. 생활 속 모순 | 손의 움직임, 남은 음식, 생각의 어긋남처럼 작은 장면을 보여준다. 첫 5~15초에 무슨 점이 이상한지 드러낸다. | 시청자가 자신의 경험에서 중심 질문을 발견한다. |
| 2. 예상해 보기 | 장면의 조건 하나를 바꿔 결과를 예상하거나 자기 경험을 떠올리게 한다. | 이 예상이 다음 연구에서 무엇을 확인할지 정한다. |
| 3. 실험과 발견 | 질문을 알아보기 위해 무엇을 바꿨고 무엇을 측정했는지 보여준 뒤 결과를 전달한다. | 시청자의 예상에 첫 답을 주고, 결과에서 자연스럽게 다음 질문을 만든다. |
| 4. 작동 원리 | 핵심 개념을 설명하고 가능한 기제와 근거의 범위를 구분한다. 도움이 되면 하나의 비유를 발전시킨다. | 개념을 안 뒤 일상 장면이 어떻게 다르게 보이는지 준비한다. |
| 5. 내 경험에 적용 | 한두 가지 구체적인 생활 장면에 설명을 적용한다. 모든 개인의 원인을 확정하지 않는다. | 시청자가 자기 상황에 가져갈 관점을 얻는다. |
| 6. 처음 장면을 다시 보기 | 첫 장면의 물건·소리·문장을 회수한다. 같은 사건을 더 구체적으로 이해하게 만든다. | 정보 요약을 넘어 해석의 변화를 보여준다. |
| 7. 작은 관찰 | 다음 한 번의 식사에서 떠올릴 질문이나 가벼운 관찰 하나를 제안한다. | 정답·성적표·억지 실천 목록 없이 자기 이해로 끝낸다. |

### 실험이 없거나 부족할 때

실험이 없는 주제도 다룰 수 있다. 사회 현상·이론·대중 개념은 각자 맞는 단계에 놓는다. 3단계는 예상에 답하는 자리이므로 실제로 관찰하거나 측정한 근거가 있어야 한다.

| 가져오는 것 | 놓을 자리 | 조건 |
|---|---|---|
| 관찰 연구·조사·통계·인터뷰 연구·책의 사례·역사적 기록 | 3단계(실험 대신) | 근거 유형을 밝힌다. 관찰·조사에서 나온 관련을 원인으로 말하지 않는다. 2단계의 예상도 그 근거가 답할 수 있는 질문(두 집단의 비교 등)으로 만든다. |
| 사회 현상(예: 혼밥, 명절 식탁) | 1단계 장면, 5단계 적용 | 3단계에 쓰려면 그 현상을 측정한 조사나 연구가 있어야 한다. 현상에 연구가 있으면 일반적인 7단계로 쓴다. |
| 이론(예: 사회비교 이론, 대상화 이론) | 4단계 작동 원리 | 3단계를 대신하지 않는다. 이론을 뒷받침하는 연구가 있으면 그 연구를 3단계에 쓴다. |
| 대중 개념(예: 크랩 심리, 가짜 배고픔) | ‘정말 그럴까?’라고 묻는 질문의 대상 | 연구가 적으면 적다고 말한다. 연구된 기제처럼 설명하지 않는다. 같은 장면을 다른 이름으로 연구한 자료가 있는지 찾는다. |

- 근거가 없으면 무리해서 넣거나 만들어내지 않는다. 3단계를 채울 근거가 없다고 알리고, 다른 편과 합치거나 인터뷰 특집처럼 7단계가 아닌 형식으로 제안한다.
- 사회 현상의 원인을 하나로 단정하지 않는다. 대중 개념이 가리키는 행동의 동기는 연구가 보여준 범위까지만 말한다.
- 근거가 약하거나 없는 해석은 구스타브의 주장으로 말해도 된다. ‘저는 이렇게 봅니다’처럼 연구 결과와 말로 구분하면 충분하며, 근거 부족을 이유로 주제를 버리지 않는다. 다만 진단·치료·의학적 안전에 관한 내용은 주장으로 대신하지 않는다.

판단 과정의 예시는 [구성 예시와 작성 형식](references/writing-guide.md)의 ‘실험이 없을 때의 배치 예시’에 있다.

## 오프닝과 시청 지속을 만드는 방식

- 기본 오프닝은 시청자의 생활 장면이다. 연도·연구자·논문·실험 장치를 첫머리에 놓는 구성은 사용자가 별도로 원할 때 선택한다.
- ‘여러분도 이런 적 있나요?’만으로 시작하지 말고, 질문할 만한 구체적 행동과 모순을 먼저 보여준다. ‘배부른데 케이크가 나온다’ 같은 익숙한 상황을 쓸 때는 새로운 관찰점이 있는지 검토한다.
- 날짜와 인물 이름을 붙인다고 서사가 생기는 것은 아니다. 사건 안의 기대, 예상과 어긋난 부분, 이후 알고 싶은 것을 연결한다.
- 열린 질문은 실제로 회수한다. 핵심 설명을 끝까지 미루기보다 7~8분 영상의 초반 1~2분 안에 첫 발견을 주는 편을 기본으로 한다. 시간은 목표이지 고정 규칙이 아니다.
- 참여 질문에 이은 빠른 답, 짧은 정적, 시점 전환, 첫 장면 회수를 사용한다. ‘충격적인 사실’ 같은 수식어를 반복하거나 관계없는 컷으로 자극을 늘리지 않는다.
- 비유를 쓰면 중심 비유 하나를 도입→설명→일상 적용에 연결한다. 비유를 실제 뇌 구조나 입증된 기제로 설명하지 않는다.
- 문장 길이는 낭독 호흡에 맞춰 변주한다. 긴 설명 뒤 핵심 단문을 두고, 모든 문장을 같은 길이로 끊거나 고정된 단문 비율을 맞추지 않는다.
- 시청 유지 데이터가 없다면 기법의 의도를 설명한다. 이탈률을 줄였다는 인과나 성과 수치를 지어내지 않는다.

오프닝·전환·회수가 막히거나 구체적 예시가 필요하면 [구성 예시와 작성 형식](references/writing-guide.md)을 읽는다. 예시의 음식과 문구를 모든 편에 복제하지 않는다.

## 연구를 대본으로 옮길 때

먼저 기존 자료와 확인된 근거를 재사용한다. 새 과학적 주장을 넣거나 논문 상태가 중요한 경우 원논문·공식 기록·적절한 종합 연구를 확인한다. 검색을 기획과 무관한 자료 수집으로 늘리지 않는다.

- 핵심 근거는 **질문 → 바꾼 조건 → 측정한 것 → 결과 → 해석 가능한 범위**로 정리한다. 필요하면 ‘주장 / 출처 / 확인 상태 / 한계’로 짧은 근거표를 만든다.
- 사용자가 붙여 준 연구 설명도 검토한다. 유명한 실험이라는 이유로 현재 유효한 결론이라고 전제하지 않는다. 정정·철회·재현 문제가 있으면 논문별로 구분하고 가능한 경우 독립 자료를 확인한다.
- 섭취량, 맛의 즐거움, 먹고 싶은 정도, 주관적 포만감, 호르몬·뇌 활동은 서로 다른 측정치다. 하나를 관찰했다고 다른 신호가 사라졌거나 원인이 입증됐다고 쓰지 않는다.
- 원연구의 보고값과 재현 연구의 결과를 구분한다. 집단 평균을 모든 시청자에게 적용하거나, 유의한 차이가 없다는 결과를 완전히 같다는 증거로 쓰지 않는다.
- 생리적 신호와 심리·환경적 단서를 근거 없이 양자택일로 만들지 않는다. 뇌과학 채널이라는 이유로 도파민·중독·뇌 회로 설명을 덧붙이지 않는다.
- 가상 일상 장면은 제작 메모에서 창작·재구성임을 밝힌다. 실제 참가자의 대사·속마음·연구자의 놀란 반응·화자의 개인 경험으로 꾸미지 않는다.
- 확인하지 못한 수치와 원문은 확인했다고 쓰지 않는다. 중요한 불확실성은 짧게 알리고, 해당 주장을 빼거나 보고·가설 수준으로 제한해 가능한 작업을 진행한다.
- 내레이션에는 이해에 필요한 한계를 자연스럽게 반영하고, 출처·세부 정정 내역·방법론 메모는 본문과 분리한다. 연구의 신뢰성에 결정적인 문제를 메모에만 숨기지는 않는다.

## 완성 전 점검

1. 오프닝에서 생활의 모순을 볼 수 있고, 실험을 듣기 전에 시청자가 품을 질문이 있는가?
2. 참여 질문, 첫 연구 결과, 다음 질문이 같은 주제로 연결되는가? 모호한 떡밥을 남기지 않았는가?
3. 3단계의 근거는 실제로 관찰하거나 측정한 것인가? 이론·대중 개념·사회 현상을 근거처럼 쓰지 않았는가?
4. 핵심 개념과 비유가 정확하며, 첫 장면을 돌아봤을 때 해석이 달라지는가?
5. 치유·회복의 느낌이 본문에서 이어지는가? 음식을 선악으로 나누거나 시청자에게 진단·죄책감·치료 약속을 주지 않는가?
6. 요청이 기획인지 실제 원고인지 부분 수정인지에 맞는 완성물을 주었는가? 예상 길이와 검증되지 않은 부분을 정확히 표시했는가?
